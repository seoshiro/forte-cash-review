# Диагностика обучаемости и локальный прототип

Исходный temporal режим плохо подгонял собственный TRAIN. Контроль с более интенсивным обучением устранил эту проблему, но не обеспечил приемлемый перенос между группами и уступил cosine baseline. Новый pack сохранён приватно и не заменяет исходный baseline. Семантическая готовность и конкурсное качество не подтверждены.

## Что измерено

Все числа восстанавливаются из `scripts/summarize_temporal_learnability.py`, `scripts/summarize_xclip_temporal_recipe.py` и [claim ledger](claim-ledger-index.md). Они читают агрегированные summaries, registration и metadata, хешируют зарегистрированные файлы и приватный pack. Отдельные предсказания и банковские кадры не читаются и не экспортируются; обучение не повторяется. При неуспешной перепроверке прежний calculation PASS отзывается.

| Проверка | Результат |
|---|---|
| Диагностика четырёх TRAIN-видео, разные группы, два класса | Исходный режим: loss 0,716570 → 0,623845, CM TN/FP/FN/TP = 2/0/1/1. Контроль B: loss → 0,000038872, CM 2/0/0/2 |
| Ранее сохранённый исходный pack на собственных 26 TRAIN | Loss 0,690720, CM 12/0/14/0; это in-sample диагностика, не validation |
| Новый B на полном TRAIN после CV | Loss 0,001724, CM 12/0/0/14; все 14 positive-point logits и 12 negative maxima имеют требуемый знак |
| Групповая проверка B, 24 LOGO / 26 уникальных видео | CM 3/9/7/7, precision 0,4375, recall 0,5, F1 0,466667; baseline CM 6/6/2/12, F1 0,75 |
| Точность кандидата | Все 14 положительных: MAE 8,571429 с против 9 с. Общие TP, n=7: 10,714286 с против 10,428571 с. Binary, point и joint gates FAIL |
| Диагностически затронутые группы | 4 группы / 4 видео: CM 1/1/1/1, F1 0,5 |
| Остальные TRAIN-группы | 20 групп / 22 видео: CM 2/8/6/6, F1 0,461538. Это тоже не независимый holdout |
| Ресурсы B | CPU 1 поток, без GPU и нового декодирования банковских видео; monitor 157,875 с, peak working set 793,847656 MiB. Это cache-training, не API latency |

Протоколы зарегистрированы до соответствующих запусков. Диагностика: `661f7ff51f0fa400b051160b77195f811b08d62360f67a1eb5b24fa7e0fa8396`. Recipe: `e29b900117bcecd387d71ec046368e885b2c0af1ab0f01d28c346006cbb8bc50`. Каждая выполнена один раз; исходники и старые packs не менялись. Новый режим выбран по fit четырёх TRAIN-групп: последующий OOF адаптивный, даже при fold-only PCA и весах. TUNE и HOLDOUT не использовались.

Проверены loss, направления градиентов, равные суммарные веса классов, padding, соответствие порогу, фактические шаги AdamW и изменение параметров. Возможность выучить TRAIN установлена; конкретная причина прежнего underfit и нового разрыва переноса не установлена. Bundled B меняет сразу learning rate, dropout, decay и число шагов.

Следующая условная гипотеза — адаптация последнего `fc2` multiframe integration transformer через малый LoRA с сильной регуляризацией и простыми сохраняющими метку изменениями яркости/контраста. Это ещё не реализованный и не измеренный эксперимент. Потребуется новый TRAIN-only prefix-cache; старых 512D embeddings недостаточно. До обучения нужен zero-adapter replay и сравнение с исходными embeddings, отдельная фиксация GPU/time/split. Дополнительная ёмкость может усилить переобучение. Другой frozen cosine ensemble эту гипотезу не проверяет.

## Что можно запустить

Из корня подготовленного проекта:

```powershell
.\.venv-patched\Scripts\python.exe scripts/run_xclip_experimental.py
```

Локальный адрес: `http://127.0.0.1:8768/`. Используется явно тестовый ключ из launcher; он не является рабочим ключом жюри. Сервис привязан к loopback. Остановка при запуске в терминале — Ctrl+C. Исследовательские endpoints: `POST /api/experimental/xclip/analyze`, `GET /api/experimental/xclip/jobs/{job_id}`. В режиме research конкурсный `/api/v1` возвращает 503.

Экран показывает кандидат, исходные JPEG, точное время, навигацию и контекст ±3 с. Тип и правило явно не установлены. Отрицательный результат не объявляет отсутствие нарушения. Исходный автоматический результат не редактируется. Ключ только в памяти страницы, результаты привязаны к владельцу задания; внешних ресурсов и аналитики нет.

`scripts/research_ui_qa.py` генерирует геометрические MOV/JPEG и перехватывает все HTTP в новом headless Edge context. Проверены положительное/отрицательное состояния, декодирование, переход к моменту, начало контекстного воспроизведения, ошибки, строгая схема, очистка старых кадров, отсутствие storage/cookies, desktop/mobile overflow. Это UI fixture, не проверка реального API transport или качества модели. Сценарий не доказывает остановку воспроизведения на границе контекста. Скриншоты остаются приватными и содержат только синтетику.

Реальные root routing, authentication и isolation отдельно проверены синтетическими TestClient tests. Локальная проверка запуска проверяет только health, пустой HTML и отказ без ключа; новых анализов она не запрашивает. Публичный URL и постоянный ключ жюри на этом этапе не созданы. Полноценное распознавание действий, классификация, применимость правил и качество на другом ракурсе остаются блокерами сдачи.
