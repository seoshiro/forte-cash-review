# HYBRID-R22-01

The saved frozen XCLIP ordered-max candidate remains the comparative baseline. It is not an accepted production detector. This experiment asks one narrower question: can a local observer check explicit physical conditions on a bounded set of XCLIP windows, followed by deterministic application of verified NB231 paragraph22, reduce false alarms without losing baseline true positives?

The protocol is `config/hybrid-protocol.json`. Registration freezes code, configuration, selected source hashes, the exact feature-cache inventory, dependency versions, model/projector bytes and hashes, and the actual native executable/DLL bytes against members of both pinned official runtime ZIPs. An exclusive attempt marker prevents duplicate runs. Rejected repeat attempts preserve previous outcomes.

Before TRAIN, fictional text checks exercise the legacy legal gate separately and the new observation schema with and without JSON constraints. Four artificial diagram sequences check the new observer. All new controls must pass. A failed positive, negative or ambiguity control stops this experiment before bank-video inference; it is not an invitation to change the prompt and retry. These fixtures check instructions, composition, geometry and OCR, not bank-video quality.

The observer receives only sampled source pixels and actual PTS. It receives no filename, label, known event point or target. It records physical observations locally. A deterministic rule requires an established working area, departure, visibly ongoing service, sufficient before/after context and distinct supporting frames. Standing up or a nearby waiting person is insufficient. Only after matching, a fixed verified event name and source citation are attached. All real observations and outputs stay private.

If controls pass, evaluation uses the same unique TRAIN contents and original groups as XCLIP. Centroids are fit inside each held-out group. All videos, including negative-margin proposals, receive at most two separated windows. Thresholds and prompts are fixed. TUNE and HOLDOUT media remain closed. Existing official-label integrity checks are disclosed separately; no claim is made that workbook labels were never read.

The comparison reports binary confusion, precision, recall, F1, timing and proposal point coverage. One official point is not exhaustive event annotation. Binary agreement cannot validate the R22 type, generated observation, applicability or evidence relevance. The narrow rule cannot cover the undisclosed complete taxonomy. No type/description accuracy ground truth is available. Research outputs are not yet wired into the API.

Qwen-stage timings include context decoding and local model work on the frozen cached XCLIP features. They exclude feature extraction and HTTP upload. Prior XCLIP extraction measurements are a separate reference. Full service latency and offline public availability require later end-to-end checks.

The original attempt timed out in native readiness before any completed control. Its status, failure and byte-exact registration are preserved. A harmless loopback-only check in the execution sandbox returned Windows10013; the separately approved temporary loopback probe outside that sandbox passed. This changes execution context without changing OS network/security settings or adding persistent grants.

`scripts/recover_hybrid_loopback.py` allows one separately recorded technical recovery only for that exact frozen startup-timeout location, before any saved control or TRAIN result. It verifies all frozen inputs, copies the original registration byte-exact, records the helper digest and amendment, and uses an exclusive attempt marker in a separate private directory. Model, prompt, rules, thresholds, splits and budgets remain unchanged. This is not a retry after semantic outcomes. A second recovery is prohibited.

Code validation: the full suite outside the network sandbox passed110 tests in20.01 seconds, with the existing nonblocking Starlette/httpx deprecation warning. Source: `.private/test-hybrid-loopback.xml`, aggregated by `.private/hybrid-tests-safe-summary.json`; individual test content is not part of model-quality evidence.

Four planned visual controls have no completed aggregate report. The stale running marker exceeded the600-second synthetic budget. The separately inspected recorded native PID had already exited; no process was killed. The terminal cause and complete observer-stage pass count are unconfirmed. No TRAIN result exists. This partial result is neither a passed prerequisite nor a bank-quality measurement; no subsequent prompt or model run is authorized by it.

An attempt to inspect raw private control responses was rejected by automatic approval review. It was not executed or retried. Only existing fixed-schema aggregates are used here. A next technical step would be an independently bounded process watchdog and per-stage safe summaries, followed by an explicit decision about any further experiment; this document does not authorize a repeat.
