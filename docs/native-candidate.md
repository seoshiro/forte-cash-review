Schema transport correction: the earlier native adapter supplied a flat response_format.schema with type=json_schema. The actual b11712 parser reads response_format.json_schema.schema and silently uses a general object schema when that nested field is absent. Its README still displays a flat example. Prior generated outputs were independently post-validated, but schema-constrained generation was not established. Historical confusion matrices remain measurements of the old adapter and are not rewritten. ORACLE-01R1 freezes the corrected transport and reruns both regular and oracle modes.

# Следующий ограниченный локальный эксперимент

GATE-01 с 2B оказался always-negative на фиксированных четырёх положительных и четырёх отрицательных TRAIN источниках. BUDGET-01R1 был always-positive. Оба отклонены; их высокий recall или specificity по отдельности не выдаётся за качество.

GGUF-01 проверяет официальный Qwen/Qwen3-VL-4B-Instruct-GGUF, Q4_K_M с F16 vision projector, на той же development-выборке. Это отдельный bundle: больше параметров, квантизация, native runtime и его image preprocessing. Причинность одного изменения не утверждается. Критерии TRAIN сохранены, seed и список источников не подбираются. Повторно использованная TRAIN-выборка не является независимой проверкой. Один TUNE допустим только после synthetic positive/negative sanity и прохождения контроля; holdout закрыт.

Официальная metadata весов указывает Apache-2.0. Текст стандартной лицензии и исходная model card сохранены локально; отдельного LICENSE в GGUF репозитории не обнаружено. Код llama.cpp b11712 — MIT, точный license text сохранён. Размер двух model artifacts — 3333461920 bytes; это размер файлов, не VRAM. Все SHA и URLs закреплены в config/gguf-artifacts.json. CUDA 12.4 выбран из официальных Windows assets: вариант 13.4 новее driver API 13.3 этого компьютера. Драйвер/ОС не меняются.

Portable runtime слушает только 127.0.0.1 на временном порту, использует заранее скачанные файлы и --offline, без Web UI, agent/tools/MCP proxy. Тестовое временное значение фиксировано и не является production credential. HTTP client не использует proxy environment/redirects. Process-local network guard допускает только точный literal loopback и выбранный порт; внешние соединения и DNS отклоняются. Никаких persistent grants и публичного tunnel нет.

GPU layers и projector запрошены явно на CUDA0 с fit=off. Действительная пригодность подтверждается только после успешной загрузки и измерения, не размером GGUF. Resource meter сообщает sampled device-wide memory, включая другие процессы; не называет её PyTorch allocation. Модель не получает filename, ID или label. Положительный gate сам по себе не создаёт событие; детали проходят registry/condition/exclusion/PTS validation и bounded refinement. cache_prompt=false, одно сообщение и одна output sequence на запрос. Исходные результаты и серверные логи остаются в .private и не читаются облаком.

Первый native тест использует только геометрию PIL: одинаковый yes/no запрос для серого, красного прямоугольника и повторного серого входа. Затем пустой доменный gate. Это проверяет visual path, отрицательную ветку и отсутствие очевидного переноса ответа. Проверка не доказывает распознавание банковских действий.

Первый тест фактически нарисовал квадрат, а спросил rectangle: положительный control провален, остальные пройдены. Report сохранён, TRAIN не запустился. Единственное последующее synthetic comparison использовало явно вытянутый прямоугольник и вопросы о red region: семь проверок (free-description lexical checks, plain yes/no, minimal JSON, rectangle JSON) прошли. Это не доказывает, что первый провал вызван исключительно формулировкой; input geometry и вопрос изменились вместе. Новый report не заменяет старый. Model load 8.75 s, observed device memory peak 3959 MiB; первая загрузка 58.906 s и peak 3965 MiB. Эти значения относятся к разным synthetic runs, не full API. Первый фиксированный TRAIN-контроль разрешён отдельной supplementary registration до его запуска.

Методологическая ссылка: [AnyAnomaly](https://github.com/SkiddieAhn/Paper-AnyAnomaly), MIT, context-aware VQA. Нейтральный короткий вопрос и ограниченный хронологический контекст используются как проверяемая идея, код и подталкивающий anomaly-score prompt не скопированы. Его экспериментальные проценты не являются нашими результатами. vLLM/CLIP stack не установлен. Текущий frozen TRAIN pipeline не меняется по ходу оценки; extraction остаётся прежним. Сравнение одного и нескольких кадров ещё не выполнено на банковских материалах.

Загрузка и тест запущены как текущая последовательность работ: prepare_gguf → run_native_when_ready → validate_native. До скачивания/проверки всех файлов GPU inference не запускается. Сырые stdout/stderr не выводятся; состояния читаются через типизированные численные/boolean safe reports. Результат пока не принят и не встроен в публичный API.

Фиксированный native TRAIN завершён: requested 8 / completed 7, invalid_observable_gate 1. Coarse/final TN/FP/FN/TP = 3/0/4/0, recall 0, balanced accuracy 0.5, F1 0. Кандидат отклонён, TUNE не запускался. Engine mean 19.76775 s / max 20.25 s; model load 11.641 s отдельно. Это не full API и не подтверждение пригодности.

На шести synthetic sequences четырёхкадровые gray/red-middle контроли прошли. Для восьми кадров gray и red-last прошли, red-first/red-middle провалились. Проверка только encoder batch 512→2048 на тех же входах дала тот же результат; гипотеза о достаточности batch-limit не подтвердилась. Оба reports сохранены. Нельзя делать вывод об отсутствии события во всех восьми кадрах при таком positional failure.

Минимальный следующий fallback — сохранить те же веса, extraction и API, проверить один image input с четырьмя хронологическими панелями и метками PTS. Это пока план ограниченного synthetic test, а не принятый detector. Collage используется только как вход модели; API evidence остаётся настоящими исходными JPEG. До положительных контролей во всех позициях и фиксированного TRAIN новый TUNE запрещён. Следует отдельно подтвердить pixel budget, память, время и отсутствие потери мелких деталей.
