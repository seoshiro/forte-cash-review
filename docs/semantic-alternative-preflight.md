# Testable alternatives if primitive facts fail

No alternative below is adopted, downloaded or claimed to fit the machine from a model name. Stop the failed Qwen path before bank/images/held-out work; preserve the current XCLIP baseline. The current runtime's actual synthetic resource measurements do not validate a different runtime or model.

## Bounded backend comparison without a new download

The already pinned Qwen GGUF weights declare [Apache2](https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct-GGUF/blob/1cd86afb9a95c410a6038ab3b40d8b578c892266/README.md); [llama.cpp code is MIT](https://github.com/ggml-org/llama.cpp/blob/b11712/LICENSE). A separately registered CPU-only text comparison can use the same fixed decomposition inputs and scoring, changing only device/offload settings. The pinned [argument parser](https://github.com/ggml-org/llama.cpp/blob/b11712/common/arg.cpp#L2505-L2514) supports `--mmproj-device none`; [device none](https://github.com/ggml-org/llama.cpp/blob/b11712/common/arg.cpp#L2634-L2641) disables offload. Combine with zero GPU layers, retaining the same artifact identities, sampling, prompt and temporary local key.

This tests backend sensitivity, not the exact GPU kernel or model capacity. CPU RAM, latency and completion still require an actual bounded preflight. A CPU pass would justify further diagnosis; it is not a deployable video detector or proof of the five-minute API limit. No CPU run was performed in this stage.

## Independent physical-state classifier

Prefer a narrow detector/tracker/state-machine route over another unbounded VLM prompt search. Candidate: [PekingU RT-DETRv2 R18 weights](https://huggingface.co/PekingU/rtdetr_v2_r18vd), whose model repository declares Apache2; the [upstream code license](https://github.com/lyuwenyu/RT-DETR/blob/main/LICENSE) is also Apache2. The locally installed Transformers RTDetrV2 model/processor classes import successfully, without loading weights or using the GPU. Built-in import is not forward-pass or memory evidence.

Proposed capability is anonymous whole-body person presence and crossing of a locally reviewed zone, followed by deterministic temporal states. No face recognition, identity, audio or role inferred from identity. This would not establish operator role, unfinished service, cash counts or legal applicability; those require separately verified observations and annotations. A bbox alone is not proof of an action.

Before adoption: pin exact upstream revision, code and weight SHA/licenses; stage only official weights; run one owned synthetic-only technical preflight with a fixed input shape, bounded load/inference, actual wall time and sampled VRAM/RAM. Apply the machine's physical VRAM limit and leave operating margin. Then evaluate the physical capability on separately authorized locally staged recordings with independently specified ground truth. No bank transition is authorized merely by a successful allocation test. Do not invent a measured speed, six-GB fit or event accuracy before this happens.

The small SmolVLM candidate was considered only through public metadata; it was not selected or downloaded. Its model card's stated use limitations must be resolved before any task adoption. This is another reason to prioritize an explicit physical-state path with a narrow, testable claim.
