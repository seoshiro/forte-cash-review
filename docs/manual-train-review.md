# Локальная проверка восьми TRAIN-роликов

Форма уже запущена только на этом компьютере. Откройте Проводником:

`C:\Users\gokusen\Documents\Codex\2026-10-17\task\forte-cash-review\.private\manual-review\Open-TRAIN-review.url`

Если сервер был закрыт, дважды щёлкните `Start-TRAIN-review.cmd` в корне проекта и снова откройте ярлык. Сам launcher не открывает браузер и не запускает видео. Альтернатива в PowerShell из корня проекта: `& .\.venv-patched\Scripts\python.exe scripts\review_train.py`.

Для каждого ролика:

1. Посмотрите видео кнопкой воспроизведения. Для положительной метки можно нажать «К отметке из разметки»; при необходимости посмотрите контекст до и после.
2. Выберите, соответствует ли официальная метка наблюдению, и достаточно ли видимости. Если не уверены, выберите «Неясно».
3. Укажите тип и публичное правило/пункт, если знаете. Иначе напишите «неясно». В комментарии локально отметьте видимые условия, исключения или несовпадение метки с правилом. Не угадывайте скрытые банковские данные и не указывайте личность людей.
4. Нажмите «Сохранить и дальше». После всех роликов напишите в чат только **«готово»**. Не отправляйте кадры, видео или пересказ отдельных случаев.

Ручной слой сохраняется в `.private/manual-review/annotations.json`; история правок — в `revisions.private.jsonl`. Официальный XLSX, исходные видео и автоматические результаты не изменяются. Пометки имеют статус `human_proposal_unverified`, `training_eligible=false`: заполнение формы само по себе не разрешает обучение и не подтверждает нормативный вывод.

Для технического контроля завершения можно читать только `.private/manual-review/progress-safe-summary.json`. Комментарии и содержательные ответы не должны попадать в облачные инструменты. Интерфейс не использует CDN, внешние запросы или облачную обработку. Доступ ограничен loopback и временной сессией процесса; это не API-ключ для жюри.

Форма привязана ровно к замороженной selection ORACLE-01R1, только TRAIN. TUNE и HOLDOUT недоступны. Реальная страница и медиа не открывались средствами browser/vision; браузерная проверка выполнялась на сгенерированном MOV с отдельным тестовым сервером.
